# Lint code

Status: Awaiting approval

Issue: BRA-124

## Purpose

Remove lint and type-check suppression directives. Fix each reported cause. Keep
the current public behavior and supported compatibility.

## Measured baseline

The tracked Python files contain these directives:

| Directive | Lines | Files |
| --- | ---: | ---: |
| `# noqa` | 48 | 38 |
| `# type: ignore` | 130 | 33 |
| `# pyright: ignore` | 13 | 7 |
| `# ruff: noqa` | 1 | 1 |
| `# pragma: no cover` | 14 | 9 |

The checked-in automation runs Flake8 through pre-commit and mypy in CI. Prior
verification records also use Ruff and BasedPyright, but the repository does
not configure or install these two tools.

## Scope

1. Remove all Ruff, Flake8, mypy, and BasedPyright suppression directives from
   tracked Python files.
2. Fix the reported cause at each site. Do not replace a directive with a
   different suppression form.
3. Keep `# pragma: no cover` directives. They control coverage measurement and
   do not suppress a lint or type diagnostic.
4. Add the minimum project configuration and development requirements needed
   to run Ruff and BasedPyright with a stable, explicit scope.
5. Preserve the current Flake8 and mypy checks.

## Constraints

- Preserve public behavior, import compatibility, wire formats, and persistence
  formats.
- Preserve JAX compilation boundaries and Brainstate transform use.
- Do not add runtime dependencies.
- Keep negative tests meaningful. Use typed helpers or explicit casts where a
  test deliberately sends invalid runtime data.
- Preserve the unrelated mode change in `docs/make.bat`.

## Verification

- Ruff reports no errors or warnings in its configured scope.
- BasedPyright reports no errors or warnings in its configured scope.
- Flake8 passes for its existing scope.
- Mypy passes for `braintrace`.
- Focused sibling tests pass for modules whose executable code changes.
- Meaningful coverage for changed executable code stays above 90 percent.
- A final search finds no Ruff, Flake8, mypy, or BasedPyright suppression
  directives in tracked Python files.

## Approval gate

Implementation starts after approval of this specification. The approver must
confirm both scope choices:

1. Keep coverage pragmas because they do not suppress lint or type diagnostics.
2. Apply the lint cleanup to all tracked Python code, not only `braintrace`.
