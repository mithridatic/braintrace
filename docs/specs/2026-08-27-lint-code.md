# Lint code

Status: awaiting approval
Issue: BRA-105

## Purpose

Remove inline lint and type-check suppressions. Fix the diagnostics instead of
hiding them. Preserve runtime behavior, public interfaces, data formats, and
JAX compilation boundaries.

## Scope

The tracked Python source contains 192 inline Ruff or type-check suppression
tokens in 73 files. The files are in `braintrace`, `examples`, and `docs`.

The baseline contains these main groups:

- 49 Ruff suppression markers
- 40 `arg-type` suppressions
- 29 `union-attr` suppressions
- 19 `index` suppressions
- 15 `call-arg` suppressions
- 13 Pyright suppressions
- 27 other type-check suppressions

Remove these suppression forms:

- `# noqa` and `# ruff: noqa`
- `# type: ignore[...]` and unqualified `# type: ignore`
- `# pyright: ignore[...]`

Keep `# pragma: no cover` markers. They control coverage measurement, not a
linter or type checker. Removing them would change the repository coverage
policy and is outside this issue.

Check the other configured static gates:

- mypy for `braintrace`
- Flake8 through pre-commit
- the repository-conventions pre-commit hook

Do not add a dependency or a broad configuration exclusion to hide a
diagnostic. Do not change the behavior of negative tests that deliberately pass
invalid values.

## Approach

1. Capture Ruff, Basedpyright, mypy, Flake8, and repository-convention
   diagnostics with their actual configured or default scope.
2. Replace suppressions with direct imports, precise annotations, protocols,
   narrow casts, typed test builders, or smaller functions as appropriate.
3. Fix remaining diagnostics in the same files without silent fallbacks.
4. Run focused sibling tests after each source group. Run the static gates and
   the affected test suites before completion.

## Acceptance criteria

- Tracked Python files contain no Ruff, mypy, or Pyright inline suppression.
- Ruff and Basedpyright report no error or warning in the agreed scope.
- mypy, Flake8, and repository-convention checks pass.
- Affected tests pass with meaningful coverage above 90 percent.
- Existing observable behavior and supported compatibility remain unchanged.
- Existing user changes outside the issue remain unchanged.

## Risks

- Some negative tests use type errors to reach runtime validation. Typed helper
  boundaries must preserve those invalid runtime values.
- Dynamic JAX, Brainstate, and Brainunit interfaces can need local protocols or
  narrow casts. A broad `Any` annotation would only move the suppression.
- Example scripts modify import paths for direct execution. Import cleanup must
  keep both direct-script and pytest execution working.

## Baseline constraint

The current execution image has Python 3.12 but does not have Ruff,
Basedpyright, mypy, Flake8, or pre-commit installed. The repository does not
configure Ruff or Basedpyright. Install or provide these tools before the final
static verification. Source inventory and repository-convention tests can run
without them.
