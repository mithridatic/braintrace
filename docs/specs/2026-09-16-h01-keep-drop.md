### Keep rule (all five must hold)

1. Finite everywhere (output site and soma, every sample).
2. Rest: the mean output-site voltage over the 100 ms before the pulse is within
   10 mV of the donor recording's rest, and the mean over the 10 ms ending 200 ms
   after the pulse is within 10 mV of the same value (returns there).
3. No -20 mV crossing before the pulse.
4. Count at the primary input inside the human count +- max(2, 30 percent of the
   human count): L2 7-13, L4 9-15, PV 9-15, SST 10-18 (integer counts, absolute
   difference <= max(2, 0.3 x human)).
5. The dt-half repeat (0.0025 ms, same everything else) reproduces the count and
   is finite. The repeat runs only for cells that hold rules 1-4; a cell failing
   any of 1-4 is dropped without it, and a cell whose repeat is missing is not kept.

### Execution

`docs/evidence/h01_keep_drop_chain.py` writes four chain scripts from the types
file (cells sorted by id, dealt round-robin), each run through
`var/h01-driven/run_transfer.sh transfer-all-<cell> 1800 -- ...`, chains pinned
to CPU sets 0-31, 32-63, 64-95, 96-127 and `MEMFRAC=.2` (four processes share the
24 GB GPU; the launcher's `.3` default would over-allocate). Measured stage C
times: 187-254 s per primary run alone, 400-1158 s per dt-half run alone; four
concurrent processes on one GPU were 2x slower in stage C. Cap per primary run
1800 s, per dt-half run 3600 s; a cap hit is untested, not dropped. Population
builds are not run at the same time (thread budget, `ps -eo nlwp` sum under 5,000).

After the primaries: `h01_anatomy_transfer_decision.py keep --phase primary`
lists candidates; the dt-half chain is generated for those only; then the final
`keep` decision writes `docs/evidence/h01-keep-drop/decision.json` with the kept
list, the dropped list and the failed rule for every drop.

Prediction, registered before launch, from stage C: cells on the L4 donor keep,
cells on the L2, PV and SST donors drop (block at -27 mV, plateau at -37 mV,
spontaneous firing). Expected order 20 keep of 104. Every cell is tested; no cell
is dropped by its donor label.

## What this does not claim

A kept cell reproduces a count and a resting level from another human donor's
recording on H01 anatomy. It is not a measurement of the H01 donor, and it does
not qualify channel provenance. The six-term ledger is regenerated over the kept
set with a `kept_cells` field; denominators and tolerances of existing terms are
not changed.
