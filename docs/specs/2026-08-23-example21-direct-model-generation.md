# Example 21 direct model generation

Status: approved for implementation

Date: 2026-08-23

Branch: `feat/example21-direct-generation`

## Objective

Produce a qualifying BrainTrace result on the complete fixed ARC evaluation
manifest. The only acceptance score is

```text
strict_task_pass_at_1_count >= 16
```

The manifest contains 400 tasks and 419 test queries. A task passes only when
the first predicted grid for every test query has the target shape and matches
every target cell. Query counts, pass@2 counts, pixel scores, shape scores, and
composite or cumulative scores are diagnostics only and must never be added to
or substituted for this integer.

## Superseded evidence

The parameter-conditioned result recorded on 2026-08-23 is not qualifying
under this contract. Its first candidates were generated by a demonstration
forest, its strict pass@1 result was 6/400, and its reported value of 30 was a
cumulative sum of four different counts. Network likelihood reranking changed
the order of forest proposals but did not generate their shapes or cells.

The forest, rule channels, demonstration-fitted decoder, and their artifacts
remain diagnostic evidence only. They may not propose, repair, select, rerank,
filter, validate, or otherwise determine an eligible prediction. No existing
score is a qualifying brain-generated baseline.

## Direct answer-path contract

For every evaluation query, one executed trained BrainTrace recurrent network
must emit logits for:

1. output height;
2. output width; and
3. every row-major output cell.

The first candidate is the fixed serialization of the argmax values from those
logits. Apart from lossless input encoding, padding removal according to the
predicted shape, and deterministic argmax serialization, no non-neural answer
logic is permitted. In particular, the eligible path has no fixed copy
residual, geometric transform, template, retrieval result, task-local fitter,
program search, forest proposal, rule proposal, or candidate-ranking stage.

Every shape and cell decision must depend on checkpoint-owned floating
trainable leaves that participated in the executed recurrent and decoder path.
The evaluator records the exact ordered dependency leaves. A provenance label
or unused model activation cannot establish ownership.

The answer path receives target-free demonstrations and the test input. The
held-out test output, exactness indicators, task-family annotations, source
identity, and target-derived selectors are scorer-only data. Replacing every
held-out target while preserving the target-free input must leave prediction
bytes unchanged.

## Architecture

The implementation adds a direct spatial decoder rather than preserving the
existing factorized candidate-likelihood head. Its minimum structure is:

- a BrainTrace recurrent encoder that consumes the complete ordered
  demonstration/query event stream;
- checkpoint-owned recurrent, memory, and readout parameters;
- learned shape heads for the 30 possible heights and widths;
- a learned coordinate-conditioned cell head that combines recurrent task
  state, encoded query information, row/column coordinates, and previously
  decoded neural state when the selected decoder is autoregressive;
- one deterministic greedy first-candidate decode.

Neuron count, neuron dynamics, synapse model, recurrent edge count, memory
width, latent depth, and decoder width are experimental design variables. They
must be declared before each scored arm and bound into its checkpoint schema
and artifact. A smaller dense recurrent core or a larger sparse core may be
used when pilot evidence justifies it. The accepted result does not inherit the
old 4,096-neuron or 4,194,304-edge requirement.

Repeated recurrent encoding, decoding, and training use
`brainstate.transform.jit`, `brainstate.transform.for_loop`,
`brainstate.transform.scan`, or a checkpointed variant. Bare Python loops may
prepare static host metadata or score already-emitted bytes, but may not drive
repeated model steps. All randomness uses `brainstate.random`.

## Training and selection firewall

Training uses ARC training tasks only. One example is treated as the query and
the remaining examples as demonstrations, with all available leave-one-out
roles sampled. Training-only augmentation may apply task-independent color,
spatial, and demonstration-order symmetries to complete episodes. Augmentation
parameters and seeds are fixed without evaluation-label feedback.

Rule engines and forests may not create pseudo-targets for evaluation inputs or
choose training episodes based on evaluation success. Evaluation targets may
be decoded only after the architecture, checkpoint, effort, and perturbations
have been nominated.

A deterministic task-level split of the ARC training set supplies development
and validation tasks. Architecture and checkpoint selection use strict
pass@1 on this validation split. The complete 400-task evaluation is deferred
until a predeclared pilot gate is met. Once complete evaluation labels are
opened, failures may be diagnosed and reported, but those labels may not tune
the next eligible run; a materially new run requires a predeclared change
justified by training/validation evidence.

Longer training arms may resume from a prior direct-model checkpoint. Resume
must load every floating parameter leaf through the exact schema validator,
must reject any architecture/path/shape/dtype mismatch, and must record the
initial checkpoint file and parameter digests. Optimizer state is deliberately
fresh unless a future artifact schema binds and validates it separately.

## Staged gates

### Gate A: contract and regression tests

Before training:

- reproduce that forest-generated or forest-reranked candidates are rejected
  from eligible scoring;
- prove target replacement leaves prediction bytes unchanged;
- prove every emitted height, width, and cell originates from direct model
  logits and has an executed checkpoint dependency;
- prove missing, extra, reshaped, or dtype-changed checkpoint leaves fail
  exact-schema validation;
- prove canonical first-prediction bytes exclude metadata and floating scores;
- prove 15 strict tasks fails and 16 passes;
- obtain more than 90 percent meaningful line coverage for changed production
  modules, including failure paths.

### Gate B: neural learning pilots

The model must first overfit a small training-task episode set and achieve
nonzero strict exact accuracy on unseen leave-one-out roles. This distinguishes
a functioning generative path from pixel-only movement.

Next, train and score a fixed task-level validation split. Promote a
configuration to full training only when its strict task accuracy and exact
memberships improve over the direct-logit baseline. Shape and pixel diagnostics
may explain failures but cannot promote an arm on their own.

### Gate C: complete evaluation

Nominate one checkpoint, decoder, effort, seed, topology, and greedy first
candidate policy before scoring the complete fixed manifest. Run all 400 tasks
and 419 queries. Acceptance requires
`strict_task_pass_at_1_count >= 16`.

## Mandatory checkpoint-dependence matrix

After a baseline reaches the threshold, evaluate five matched arms on identical
target-free inputs:

1. trained baseline;
2. intact checkpoint reload/repeat;
3. every floating answer-path trainable leaf scaled by the predeclared factor
   0.5;
4. every answer-path trainable leaf deterministically reseeded with the
   predeclared `brainstate.random` seed 73; and
5. an independently trained same-schema checkpoint with a different training
   seed.

The repeat must have byte-identical first predictions and the identical strict
pass@1 result. Each of scale, reseed, and swap must independently have:

- a different parameter digest;
- different ordered first-prediction grid bytes, where bytes encode predicted
  height, width, and row-major colors only; and
- a different `strict_task_pass_at_1_count`.

A flat perturbation fails qualification even if logits, metadata, internal
state, query counts, or diagnostic scores change. NaN/Inf output and schema
drift fail closed. Dale-sign evidence is not claimed unless a separate matched
sign intervention and zero effective sign violations are recorded.

## Artifact contract

Each arm binds and records:

- source revision and dirty state;
- evaluation-manifest digest and ordered 400 task/419 query membership;
- architecture, neuron dynamics, synapse configuration, topology, and their
  digests;
- ordered parameter paths, shapes, dtypes, individual hashes, checkpoint hash,
  and parameter digest;
- training seed, evaluation seed, and checkpoint selection evidence;
- ordered first-prediction bytes and digest;
- exact per-query membership, exact per-task strict membership, and
  `strict_task_pass_at_1_count`;
- perturbation kind and exact schema comparison;
- proof that the scorer alone received held-out targets.

The final report leads with the single strict pass@1 integer and lists its exact
task membership. It may report diagnostics separately, but must not present a
cumulative score. Until both the threshold and every causal gate pass, the
result remains unqualified.
