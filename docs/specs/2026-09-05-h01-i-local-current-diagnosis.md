# H01 I local current diagnosis

Continue the approved I response diagnosis with the frozen candidate. Add
read-only soma probes for transient sodium activation and inactivation and
for sodium and potassium channel currents. Keep the original 1 nA pulse,
2 ms onset, 3 ms duration, dt 0.005 ms and maximum CV length 10 um. Use the
existing soma location, so observation does not introduce a new mesh location.
Compare the complete voltage trace with the uninstrumented baseline before
using the observations. Save units and current sign explicitly.

Read direct currents and gates at pulse onset, the voltage peak, pulse end,
and recovery. This is a localization step, not a causal intervention. Do not
infer a complete current balance without axial, applied and all membrane
currents. Use the results to select a subsequent one-factor intervention;
do not tune parameters or change the acceptance threshold in this step.
