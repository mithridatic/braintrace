# Earlier sodium-density split has unequal phase effects

This retrospective review uses the earlier command-only split, with
original Ih and passive reversal. It does not use the current distributed
Ih candidate. The original combined prediction was rejected.

For the first event, reducing NaTs density by 10 percent lengthens the
rise-to-peak time from 0.117043 to 0.121008 ms. The human value is
0.288444 ms. Peak-to-fall time decreases from 0.797781 to 0.774529 ms;
the human value is 0.647419 ms. Thus the total duration becomes shorter
although the rising phase becomes longer.

All five events show a longer rising phase and shorter falling phase
under this intervention. The [individual values](h01-l2-sodium-density-phase-review.json)
retain each event and the source artifact hash. There was no prospective
phase hypothesis for this earlier run. Its candidate numerical checks
remain incomplete. These observations cannot establish the effect of
the same density change in the current model setting.

The small rising-phase response does not support assuming that a modest
density reduction alone will repair the large rising-phase error. Gate
kinetics and other current paths remain possible diagnostic targets;
this review does not identify a unique cause.
