Both updates had finite losses and gradient norms; optimizer and eligibility

exactly. The compiler emitted two warnings for readout parameters absent from
the recurrent graph; the learning report nevertheless records changed readout
parameters and finite optimizer state. This is not a zero-warning result.

Comparisons are single-run historical measurements, not repeated controlled
